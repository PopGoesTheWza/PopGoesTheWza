## I take issues and solve problems. Sometimes even on GitHub.

Lead Architect at **Rigby Capital** in Paris, France. I spend my days migrating on-premise systems to Azure and my evenings convincing TypeScript to behave. Currently exploring agentic-assisted programming with [OpenCode](https://opencode.ai) -- because apparently writing code yourself is _so 2024_.

---

### A bit about me

- I'm currently building agentic-assisted development workflows and migrating enterprise systems to **Azure** (on-prem to cloud -- the fun kind of migration)
- I was a major contributor to Google's [clasp](https://github.com/google/clasp) -- the CLI that lets you develop Apps Script locally like a civilized person
- I brought TypeScript support to [stampit](https://github.com/stampit-org/stamp) -- because OOP with stamps deserved proper types
- I built an entire ecosystem of Google Sheets tooling for **Star Wars: Galaxy of Heroes** -- API wrappers, Territory Battles management, and guild coordination tools used by real guilds managing real (fictional) galactic wars
- Ask me about **TypeScript**, **Google Apps Script**, or why spreadsheets are a perfectly valid application platform
